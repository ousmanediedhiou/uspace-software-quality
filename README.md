# USpace — Développement logiciel et assurance qualité

**Projet universitaire | Université Laval | IFT-6006 — Qualité logicielle**

## Présentation du projet

USpace est une application de gestion et de réservation de croisières spatiales, utilisée dans le cadre du cours **IFT-6006 — Qualité logicielle** à l'Université Laval.

Le projet s'articule autour de quatre travaux pratiques (TP) progressifs permettant de mettre en application des concepts de développement logiciel, de conception orientée objet, de tests automatisés et d'assurance qualité.

Ces travaux ont permis de développer des compétences techniques en programmation Java, en développement d'API REST, en gestion de bases de données et en validation de logiciels.

## Technologies utilisées

| Domaine | Technologies |
|---|---|
| Développement backend | Java, API REST |
| Persistance des données | Hibernate ORM, H2 |
| Développement frontend | Vue.js, Vite |
| Tests unitaires | JUnit 5, Mockito |
| Tests comportementaux | Cucumber |
| Tests frontend et bout en bout | Vitest, Cypress |
| Gestion de projet | Maven, Git, GitHub |

## Fonctionnalités du projet

Le projet couvre plusieurs fonctionnalités :

- Gestion des planètes et des voyageurs.
- Gestion des réservations de croisières spatiales.
- Validation des données et gestion des exceptions.
- Gestion des comptes utilisateurs.
- Attribution des cabines selon des critères de priorité.
- Gestion des manifestes des navettes d'urgence.
- Développement et validation des interfaces utilisateur.

## Organisation des travaux pratiques

### TP1 — Développement et validation des fonctionnalités

Travail sur les fonctionnalités de l'application, les API REST, la validation des données et les tests unitaires.

### TP2 — Architecture et qualité du code

Travail sur la persistance des données, la conception orientée objet, le réusinage du code et l'application des principes SOLID.

### TP3 — Stratégies de tests logiciels

Mise en pratique des tests de composants, des tests d'intégration et des tests comportementaux avec Cucumber.

### TP4 — Fonctionnalités métier et tests automatisés

Travail sur l'attribution des cabines, la gestion des navettes d'urgence, les tests automatisés et les fonctionnalités frontend.

## Compétences développées

### Développement logiciel
- Programmation orientée objet en Java.
- Développement et compréhension d'API REST.
- Organisation du code en couches.
- Gestion des exceptions et validation des règles métier.
- Persistance des données avec Hibernate.

### Assurance qualité logicielle
- Conception et exécution de tests unitaires.
- Utilisation de JUnit et Mockito.
- Tests de composants et d'intégration.
- Tests comportementaux avec Cucumber.
- Tests d'interfaces utilisateur avec Cypress et Vitest.
- Analyse de la qualité et de la fiabilité du logiciel.

### Génie logiciel
- Compréhension et évolution d'une application existante.
- Application des principes de conception logicielle.
- Utilisation de Maven pour la gestion des dépendances.
- Utilisation de Git et GitHub pour le suivi du code.

## Objectif du dépôt

Ce dépôt présente les travaux pratiques réalisés dans le cadre du cours IFT-6006 à l'Université Laval.

Il a pour objectif de mettre en valeur les connaissances et les compétences acquises en développement informatique et en assurance qualité logicielle.
